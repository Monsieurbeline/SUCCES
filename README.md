# Outils SUCCES (Anniversaires + Certificats de stage)
Une seule application : connexion unique, menu latéral, deux outils.
Déposer **tous** les fichiers à la racine d'un dépôt GitHub Pages. Identifiants : `index.html` (const USER/PASS) et `anniversaires.html` (même ligne) — à changer aux deux endroits.
Mise à jour : changer `V` dans `sw.js`.

Outils : Anniversaires, Certificats de stage (QR + vérification), Communiqués, Simulateurs crédit/épargne, Vérification publique (verification.html, sans connexion).
Les taux de crédit ne sont pas publiés : ils se saisissent dans le simulateur. Le sel de signature du QR (SEC) est dans certificats.html et verification.html.

Synchronisation Google : voir le menu « Synchronisation » (mode d'emploi) et google-apps-script/Code.gs. config.js = URL publique pour la vérification des QR.
