Caisse Populaire SUCCES

🔄 Synchronisation Google Sheets + Drive





Mode d’emploi (à faire une seule fois)

    

  1. Créez un Google Sheet vide, par exemple « SUCCES – Données », avec le compte Google de la Caisse.
    2. 

  2. Menu Extensions → Apps Script. Supprimez le code existant et collez le contenu du fichier google-apps-script/Code.gs.
    3. 

  3. Remplacez CHANGEZ-MOI… par une longue phrase secrète (au moins 20 caractères), puis enregistrez.
    4. 

  4. Déployer → Nouveau déploiement → Application Web : Exécuter en tant que : Moi ; Qui a accès : Tout le monde. Autorisez l’accès à Sheets et Drive, puis copiez l’URL se terminant par /exec.
    5. 

  5. Collez l’URL et la clé ci-dessus, cliquez Tester puis Synchroniser. Répétez sur chaque appareil (même URL, même clé).
    6. 

  6. Pour la vérification publique des certificats : collez la même URL (sans la clé) dans le fichier config.js du projet.
    7. 

  7. Après toute modification du script : Déployer → Gérer les déploiements → Modifier → Nouvelle version.


Les images (photos, signature) sont rangées dans le dossier Drive « SUCCES-images », qui reste privé. Dans le Sheet, la colonne « json » est la source : modifiez les données dans l’application, pas dans le Sheet.
